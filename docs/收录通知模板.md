# 上游作者收录通知模板

> 每收录一个上游开源项目,给作者发一封(GitHub Issue / Gitee Issue / 邮件均可)。
> 原则:先斩后奏但立刻告知 + 无条件下架承诺 + 给徽章不强求。首封(LinysBrowser)见下,后续替换应用名即可。

---

标题:LinysBrowser 已被收录进 HapLane Registry(鸿蒙开源应用仓,可一条命令安装)

你好!

我在维护一个鸿蒙开源应用仓 [haplane-registry](https://gitee.com/LeonTing1010/haplane-registry)(类似 F-Droid 的思路:只收开源与开发者自有作品,不收破解/魔改包)。

已按 MIT license 原样收录你在 Release 发布的未签名包(v2.0.0-beta 的 HMOS/OHOS 两个变体 + v1.8.1-beta 兼容版),保留你的署名与源仓链接。用户可以这样一条命令安装(下载后本地自动签名,不改动你的包内容):

```bash
npx -y haplane deploy --app linysbrowser
```

三件事:

1. **如果你不希望被收录,回一句,立刻下架**,不用理由。
2. 以后你发新版,欢迎开 Issue 或提 PR 同步(条目模板一条命令生成);也可以我这边跟进。
3. 愿意的话可以在 README 贴个徽章(完全可选):

```markdown
[![haplane registry](https://gitee.com/LeonTing1010/haplane-registry/raw/main/badge.svg)](https://gitee.com/LeonTing1010/haplane-registry)
```

谢谢你把包开源出来。
